This script used DolphinTool to convert the ISO to RVZ. So the C++ Redistributable needs to be installed in order for this to work. If there are a bunch of DLL errors, please download the latest version here: https://aka.ms/vc14/vc_redist.x64.exe
There is also an NKit version that doesnt depend on the Visual C++ Redistributable.
MAKE SURE TO PLACE THE BATCH FILE INTO THE SAME LOCATION AS THE ISO FILES!!!
